## 交付结果

### 已接入 Ark 官方目录

| 类型 | 模型 |
| --- | --- |
| 图片 | Seedream 4.0、4.5、5.0 Lite、5.0 Pro |
| 视频 | Seedance 2.0、2.0 Fast、2.0 Mini、2.5 |

模型能力完全来自服务端声明，不按显示名称猜测。图片参数包括按模型约束的尺寸/自定义宽高、输出格式、水印、提示词优化模式；支持组图的模型另有组图模式和最大张数。`response_format=url` 与当前任务所需的非流式模式由服务端固定，不暴露为普通用户控件。

图片自定义尺寸在 API 与适配器两层使用同一约束验证。嵌套供应商参数通过白名单路径重新构建，不合并浏览器对象，并拒绝重复目标、危险键和未声明参数。

### 已接入内置提示词 Skill

| Skill | 用途 |
| --- | --- |
| 精准结构 | 主体、环境、构图、风格和限制条件 |
| 摄影写实 | 镜头、光线、景深、材质和摄影语言 |

Skill 指令为本项目原创，方法参考和固定提交见 `THIRD_PARTY_NOTICES.md`。普通用户只能选择管理员启用的内置条目；浏览器拿不到真实指令、Key 或服务地址。未配置管理员文本模型时，目录仍可查看，但执行会明确显示不可用，不会伪装成功。
