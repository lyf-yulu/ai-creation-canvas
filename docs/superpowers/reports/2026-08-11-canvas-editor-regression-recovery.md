# 画布编辑器回归修复报告

日期：2026-08-11  
分支：`agent/graph-media-nodes`

## 交付结果

- 媒体集合节点在 0–8 项时按内容自然增高，超过 8 项后改为节点内有界滚动。
- 同一用户从画布切到资产或任务后，项目入口返回最近编辑的画布；切换用户时不会继承前一用户的画布地址。
- 画布左侧提供明确的“返回项目列表”入口。
- 一个画布可创建多个提示词节点；每个模型的提示词输入仍只允许一条有效连接。
- 同一画布可独立运行多个模型任务；成功后模型状态变为“已完成”，结果节点和 `模型结果 → 结果节点` 连线会幂等创建。
- 已接受但最终失败的任务会显示“失败”，不会残留“排队中”并锁死操作。
- 空白背景平移在父组件更新后仍持续响应，可跨多个 pointer move 连续移动。
