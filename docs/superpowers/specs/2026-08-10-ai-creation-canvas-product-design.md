# AI 创作画布产品化设计规格

日期：2026-08-10

状态：已获用户书面批准（2026-08-10）

适用仓库：`ai-creation-canvas`

实施方式：小步 RAE 垂直切片；本规格获批前不编写实施计划或功能代码

## 1. 目标与成功标准

“AI 创作画布”要从已验证的技术底座发展为可直接打开和测试的 Web 产品。它以无限画布承载图片、视频、Dreamina、人像与后续工作流能力，服务端沿用已经成熟的 Portal 身份、资产、任务、用量和管理思想，但不依赖原生产仓库运行。

本阶段的最终目标是：

1. 本地一条命令启动，浏览器打开真实产品 UI。
2. 功能对齐 `ai-generation-portal`，明确排除飞书 Agent 与飞书日报。
3. 管理员在服务端配置和派发模型及密钥；普通用户只选择被派发的模型和参数。
4. 使用一个管理员账号和一个普通用户账号完成双端、双角色、跨用户隔离验收。
5. 使用命名 Cloudflare Tunnel 做 1–2 人轻量测试，不把长任务绑定在长 HTTP 请求上。
6. 本地版通过后，业务代码可以切换到 PostgreSQL、对象存储和 Redis，支持未来多实例、多地区部署；服务器容量和地域由部署方决定。
7. 保留 ComfyUI 工作流服务和内置 Skill 的受控扩展接口，不在首轮一次性实现全部扩展。

## 3. 设计原则

1. **Portal 内核、画布外观。** 复用身份、治理和任务语义，不把旧 Portal iframe 作为最终产品 UI。
2. **模型是声明，不是分支。** Nano Banana、Seedance 等是可选模型或兼容实现，不是写死的一级后端。
3. **普通用户无密钥操作。** 用户只选模型、参数和资产；Key、供应商地址和模型派发属于管理员。
4. **先记录，再调用。** 服务端先留下可恢复的任务意图，再执行可能计费的模型请求。
5. **不确定时不重提。** 无法确认上游是否已创建任务时只查询或人工确认，不自动重复付费提交。
6. **大文件不整体缓冲。** 上传分块、结果流式、视频支持 Range。
7. **本地和云端共享业务契约。** 存储与队列可以替换，前端、权限和任务状态机不变。
8. **扩展受控。** ComfyUI 和 Skill 只能通过版本化、可审核的能力接口进入，不能绕过权限和用量治理。
9. **小步 RAE。** 每个增量有可打开的界面、可复验的主链路和明确回滚点；密钥、付费调用、迁移和多用户隔离继续采用严格门禁。

## 4. 信息架构与真实 UI

### 4.1 普通用户页面

| 页面 | 职责 |
| --- | --- |
| 工作室 | 无限画布、节点编排、右侧节点设置、底部任务托盘 |
| 项目 | 项目、主题工作区、草稿、预设、模板 |
| 资产库 | 上传、分组、重命名、复用、下载及回流画布 |
| 任务中心 | 队列、进度、失败原因、停止、恢复与任务详情 |
| 历史 / 归档 | 图片和视频结果、活动记录、归档和再利用 |
| 模板与 Skill | 运行管理员启用的内置模板和 Skill |
| 我的用量 | 本人额度、并发占用和使用记录 |

工作室采用三栏加底部任务托盘：左侧为导航与节点库，中间为画布，右侧为当前节点设置，底部集中显示运行任务。移动或窄屏时隐藏次级检查器并允许任务托盘换行，不允许底栏覆盖画布内容。

### 4.2 管理员后台

管理员后台与创作工作室分开，包含：

- 用户创建、启停、角色与一次性密码重置。
- 服务凭据的设置、替换和连接测试；保存后不可回显原值。
- 模型目录同步、启停以及按用户或角色派发。
- Dreamina 账号池、登录状态、活动账号和调度策略。
- 用户额度、并发、文件大小、保留周期和队列策略。
- 今日、用户、日期范围、趋势、活动和 CSV 统计。
- 内置 Skill 的启停、版本、校验和与回滚。

管理员默认可以查看用户资产和任务的元数据及审计编号，不默认直接浏览用户创作内容。后续如需支持工单查看，应增加显式授权和审计动作。

### 4.3 黑绿科技主题

- 主背景使用近黑色分层面板，荧光绿只用于主动作、连线、焦点和成功状态。
- 正文使用高对比浅灰绿，不使用纯荧光绿承载长文本。
- 错误、警告、排队、禁用和焦点不能只依赖颜色区分，必须同时有文字、图标或边框。
- 画布、iframe 容器、媒体预览、透明图片、右侧面板和底部托盘均使用独立底板与边界。
- 页面为底部托盘预留安全高度；缩放、窄屏和 iframe 场景不得遮挡内容或造成黑底文字不可见。
- 组件需通过键盘焦点、常用对比度、200% 缩放、窄屏和 iframe 嵌入检查。

## 5. Portal 功能对表

### 5.1 进入画布的创作能力

- 文字、提示词和经过审核的提示词优化 Skill。
- 上传资产、资产引用、参考图片、视频和音频输入。
- 通用图片文生图、参考图编辑、尺寸/比例/格式/种子及模型声明参数。
- 通用视频文生视频与图片参考视频。
- Seedance 兼容能力：首尾帧、多图片、视频/音频参考、时长、分辨率、比例、种子、音频、水印、延长、编辑和服务端声明的扩展参数。
- Dreamina 图像、视频、帧生视频、多模态和多帧能力。
- 人像流程：虚拟人图片上传资产库取得 `asset_id`，再进入通用视频调用。
- 结果节点、组合、批量、停止、恢复、再次编辑及结果回流。

控件完全由服务端 `ModelSpec` 能力与安全参数结构生成，不根据显示名称猜测功能。新增模型原则上只增加目录声明或适配器，不修改画布任务核心。

### 5.2 放在独立页面的配套能力

- 主题工作区、草稿、预设、模板、归档和批量记录。
- 资产分组、重命名、复用、下载和生命周期。
- 作业队列、活动、历史、失败详情、恢复与下载。
- 个人用量和额度状态。

### 5.3 管理员专属能力

- 用户、模型、凭据、额度、并发和用量统计。
- Dreamina 多账号、活动账号和调度。
- Skill 生命周期治理。

### 5.4 明确排除或安全替代

- 飞书 Agent 与飞书日报本阶段不实现；未来飞书应用和 Key 仍由管理员在服务端派发。
- 原 Portal 的个人明文 Key 仓库不迁移，以管理员 secrets 管理和模型派发替代。
- 普通用户不能配置任意供应商、Base URL、远程插件或动态脚本。
- 首版本不执行真实 ComfyUI，只保留受控工作流服务契约。

## 6. 总体架构

```text
浏览器 / Cloudflare 命名 Tunnel / 未来域名
                     │
            静态 React 混合创作工作室
                     │  同源 /api/v1
                     ▼
              Python 控制平面
   ┌─────────┬─────────┬────────┬──────────┐
   │身份/角色│模型目录 │资产治理│任务/用量 │管理员配置
   └─────────┴─────────┴────────┴──────────┘
                     │
            版本化受控适配器边界
       ┌────────┬────────┬────────┬────────┐
       │图像服务│视频服务│Dreamina│人像流程│未来 ComfyUI
       └────────┴────────┴────────┴────────┘
```

### 6.1 画布能力层

- 节点注册表声明稳定 ID、版本、输入/输出端口、设置结构、渲染器和动作。
- 端口使用媒体与业务类型校验连线，避免把不可用资产交给模型。
- 工作流执行器按拓扑顺序运行，可停止尚未开始的下游节点。
- 节点能力清单必须与真实实现和测试一致，不能只显示未实现功能。
- 画布存储携带结构版本，迁移集中管理；显示名变化不能破坏历史项目。

### 6.2 Python 控制平面

它是唯一可信业务入口，负责：

- 会话、角色、用户作用域和 CSRF/Origin 校验。
- 模型目录过滤、参数二次验证和用户模型派发。
- 资产归属、上传会话、结果引用和下载授权。
- 任务幂等、队列、租约、状态恢复、用量与审计。
- 管理员配置、secret_ref 和服务适配器装配。

浏览器不能提交可信用户 ID、角色、owner、密钥或目标服务 URL。

### 6.3 适配器边界

一级适配器按业务能力划分为图片生成、视频生成、Dreamina 和人像工作流。Seedance 是视频适配器可支持的正常模型族；人像是“资产上传 + 视频任务”的编排模块，不是第三个固定模型后端。

未来 ComfyUI 以版本化 `WorkflowService` 接口接入，最少描述工作流 ID、版本、输入/输出端口、参数结构、所需权限和可取消能力。首版不接受普通用户自定义远程地址。

## 7. 任务与文件数据流

### 7.1 标准生成闭环

1. 浏览器获取当前会话和已派发模型目录。
2. 用户选择模型、参数和本用户拥有的资产。
3. 大文件按 8 MiB 分块上传；服务端检查会话、类型、文件头、总大小、哈希和完整性，完成后返回不透明 `asset_id`。
4. 浏览器在提交前生成并持久化作用域内的幂等标识。
5. 服务端在事务中复验用户、模型、参数、额度、并发和所有引用资产，先写入 `queued` 任务。
6. 执行器领取有时限租约，通过受控适配器调用模型服务。
7. 服务端流式接收结果进入资产库，登记 owner/project/job，只向浏览器返回不透明 `result_ref`。
8. 浏览器使用 2–10 秒退避短轮询查询；成功后按 `sourceJobId` 去重回填结果节点。
9. 页面刷新或切回项目时只用 GET 恢复现有任务，不能重新 POST。

### 7.2 任务状态

```text
draft → queued → submitting → running → succeeded
                     ├──────→ failed
                     ├──────→ cancelled
                     └──────→ reconcile_required
```

- 排队任务可以确定取消。
- 运行任务仅在供应商声明支持时传递取消；停止页面轮询不能显示为供应商已退款。
- 供应商明确拒绝且确定未创建任务时，才允许按策略重试。
- 若连接中断且无法判断是否创建任务，进入 `reconcile_required`。已有上游任务 ID 时只查询；没有可查询标识时提示人工确认，不自动重提。
- 用户显式重试复用原重试令牌；普通重复点击由服务端幂等约束合并。

### 7.3 文件吞吐策略

本地轻量测试默认限制：

| 项目 | 限制 |
| --- | ---: |
| 单张图片或人像 | 20 MB |
| 单次视频/音频参考资产总量 | 256 MB |
| 上传块 | 8 MiB |
| 普通用户同时活跃生成 | 2 |
| 本地全局同时活跃生成 | 4 |

超过并发进入队列；超过文件限额立即拒绝。Web 进程不得把完整视频、音频、上传请求或上游结果整体读入内存。

本地模式把分块写入受控临时目录，完成后原子转入资产库；云端模式使用分块或短时签名直传 S3/R2，API 负责签发、核验和登记。结果读取支持 GET、HEAD、Range、断点读取和私有缓存策略。

删除项目先解除引用；文件根据管理员保留策略延迟清理，避免共享资产或进行中任务被误删。

## 8. 身份、权限与密钥

### 8.1 账号与会话

- 公开注册默认关闭，只能由管理员创建、启停用户和重置密码。
- 初始化命令生成一个管理员和一个普通用户，并只在终端显示一次随机初始密码；首次登录要求修改。
- 账号、密码、Cookie 和真实密钥不进入 Git、截图或设计文档。
- 云端 Cookie 使用 `HttpOnly`、`Secure` 和适当 `SameSite`；登录后轮换会话标识，退出时服务端撤销会话。
- 所有状态变更校验同源 Origin/CSRF；所有资源操作同时校验会话、角色和 owner。

### 8.2 浏览器隔离

浏览器持久状态按“部署环境 + 服务端用户作用域”分区。退出或用户切换时立即中止旧作用域轮询、清理内存状态并切换存储命名空间。旧请求晚返回时必须被作用域租约拒绝，不能写入新用户画布。

### 8.3 资源隔离

- asset、job、project、result、usage 和 upload session 均记录权威 owner。
- ID 不包含可信权限；即使猜中 ID，也必须再次校验归属。
- 跨用户读取统一返回资源不存在，避免泄露对象是否存在。
- HEAD、Range、短时下载能力与普通 GET 使用同一归属检查。
- 管理员操作写入脱敏审计记录。

### 8.4 密钥管理

- 浏览器只提供设置、替换和测试连接动作，不能读取保存后的值。
- 生产使用环境 secrets 或专用 secrets 后端；本地使用仓库外、权限受限的独立密钥文件。
- 数据库只保存 `secret_ref`、脱敏状态和更新时间。
- 日志、错误、任务参数、审计和导出递归脱敏，不记录原始上游响应、内部 URL 或长期下载地址。

## 9. 错误与用户恢复

统一错误至少包含稳定 `code`、安全中文 `message`、`retryable`、`trace_id`、失败阶段和可选字段级问题，不返回堆栈、Key 或原始上游正文。

| 类别 | 用户提示与动作 |
| --- | --- |
| 参数错误 | 指出字段和允许范围，修改后提交 |
| 额度或并发 | 说明排队、额度或限制，等待或联系管理员 |
| 上游明确拒绝 | 受控原因和错误编号；仅在 `retryable` 时显示重试 |
| 状态不确定 | 明确“系统没有重新提交”；只允许继续查询或人工确认 |
| 无权访问 | 统一显示资源不存在 |
| 系统故障 | 安全概述和 `trace_id`；允许安全重试或报告 |

失败节点保留提示词、参数、引用资产和任务来源。人像资产已成功但视频失败时可以复用原 `asset_id`。错误态使用文字和图标，不仅使用颜色。

## 10. 本地、Cloudflare 与云端运行档

### 10.1 本地轻量档

- SQLite 保存权威业务记录。
- 本地私有目录保存资产和结果。
- 进程内队列执行任务，任务状态持久化；进程重启后扫描未完成任务恢复。
- Python 同时提供静态 UI 与同源 API，生产运行不需要 Node/Bun。

### 10.2 Cloudflare 轻量测试

使用命名 Cloudflare Tunnel 暴露本地 Python 服务。生成接口快速返回 `202`，任务使用短轮询；上传按块，下载支持 Range。Quick Tunnel 仅可用于临时开发，不作为验收入口。

设计依据是 Cloudflare 当前公开限制：Free/Pro 代理请求体上限 100 MB，代理读取超时 125 秒；Quick Tunnel 还有并发和功能限制。相关实现不得依赖这些上限恰好不变，部署前应复核官方文档：

- <https://developers.cloudflare.com/support/troubleshooting/http-status-codes/4xx-client-error/error-413/>
- <https://developers.cloudflare.com/fundamentals/reference/connection-limits/>
- <https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/>

Cloudflare 本轮仅供 1–2 人轻量测试，不承担大规模媒体中转或正式 SLA。

### 10.3 云端多用户档

- PostgreSQL 代替 SQLite。
- S3 或 R2 代替本地资产目录。
- Redis 提供队列、租约与协调。
- API 无状态化，多实例不依赖粘性会话。
- 数据库为任务状态权威源，对象存储为媒体权威源，租约防止重复执行。

先用本地容器执行同一套适配器和多实例契约测试，再接真实服务器。功能侧保证无状态、归属、幂等和可替换基础设施；节点规模、带宽、跨区数据库和成本由部署方案决定。

## 11. 内置 Skill 与未来 ComfyUI

### 11.1 内置 Skill

首版只允许仓库内或管理员批准的内置 Skill。每个 Skill 具有：

- 稳定 ID、语义版本和显示元数据。
- 输入/输出结构与所需业务权限。
- 内容清单和校验和。
- 最低应用版本、迁移说明和回滚版本。
- 自动化合同测试与管理员启停状态。

普通用户只能运行已启用 Skill。增量更新采用下载、校验、隔离验证、原子启用和可回滚流程；不允许 Skill 获得任意服务器命令、浏览器脚本、密钥读取或绕过用量统计的能力。

### 11.2 ComfyUI

首版仅定义工作流适配器、能力清单、输入输出端口和任务状态映射。后续由管理员登记受信服务和审核过的工作流，普通用户只看到已派发的工作流节点。任意 URL、任意工作流 JSON 和浏览器直连均不开放。

## 12. RAE 垂直切片

每个切片都必须独立可运行、可演示、可回滚，不能等全部功能完成后一次验收。

### Slice 1：真实 UI 与无付费主链路

- 一条命令启动并打开浏览器。
- 管理员和普通用户登录，显示不同导航。
- 管理员使用模拟目录派发模型；普通用户只能选择被派发模型。
- 普通用户创建项目，在画布添加提示词和图片生成节点。
- 模拟任务经真实 `/api/v1/jobs` 状态机回填结果节点。
- 刷新后项目与任务恢复；自动化测试使用两个普通用户夹具证明项目互不可见。
- 不接真实 Key、不产生付费请求。

### Slice 2：图片完整能力

图片生成、参考图编辑、工作区、草稿、归档、批量、资产和下载。先使用合同服务，管理员明确配置测试 Key 后才运行代表模型烟测。

### Slice 3：视频与 Seedance 兼容能力

文生视频、图片参考、首尾帧、多图片、视频/音频参考、延长、编辑、队列、恢复和 Range 播放。

### Slice 4：Dreamina

图像、视频与多模态能力；管理员账号池、登录状态、活动账号和调度策略。

### Slice 5：人像

虚拟人图片上传资产库、分组、重命名、复用、视频生成及历史；全程使用不透明 `asset_id`。

### Slice 6：治理与 Cloudflare

统计、趋势、活动、CSV、额度、并发、保留期和命名 Tunnel 轻量双账号验收。

### Slice 7：云端运行档

PostgreSQL、对象存储、Redis 适配器及本地容器多实例契约测试。此切片验证未来上云能力，不在本机搭建正式生产环境。

## 13. 测试与验收

### 13.1 自动化层次

1. 领域单元测试：状态机、能力结构、参数校验、作用域和迁移。
2. 适配器合同测试：身份、目录、资产、任务、结果、用量和各生成服务。
3. 集成测试：SQLite/本地文件与 PostgreSQL/对象存储/Redis 两种运行档。
4. 浏览器行为测试：真实页面、节点操作、刷新、切换账号、错误和媒体播放。
5. 安全负向测试：伪造身份、跨用户 ID、非法上传、路径穿越、外部 URL、错误 Origin、动态脚本和敏感信息泄露。
6. 发布测试：可复现前端构建、静态 Python 运行、发布包清单和篡改拒绝。

### 13.2 双角色交付与跨用户验收矩阵

- 管理员创建/停用普通用户，派发模型，设置额度；普通用户不能访问管理接口。
- 自动化和集成测试额外创建两个临时普通用户夹具，验证其项目、浏览器状态、资产、任务、结果、历史和用量完全隔离；测试后删除夹具和数据。
- 用户切换时旧轮询被取消，晚返回不能写入新作用域。
- 结果 GET/HEAD/Range、下载和历史使用相同 owner gate。
- 手工验收和最终交付只提供两个账号：一个管理员、一个普通用户。初始化命令生成随机一次性密码，密码不写入仓库。

### 13.3 任务与文件验收

- 刷新和断网只恢复原任务，不重复 POST 或重复结果节点。
- 明确拒绝、可重试错误、状态不确定、超时、取消和结果过期分别测试。
- 每个上传块和总文件大小均受限；缺失长度头也按实际累计大小拒绝。
- 文件流在单次取消、清理期间再次取消和读取异常时仍可靠关闭，不能发生文件描述符复用误读。
- 大文件上传和结果读取测量峰值内存；视频 Range 返回和拖动播放通过。

### 13.4 共同发布门槛

每个切片进入下一阶段前都必须满足：

- 用户可实际打开并完成该切片主链路。
- 自动测试、类型检查、静态构建、安全扫描、密钥扫描和差异检查通过。
- 浏览器、静态产物、日志、审计和 CSV 无真实 Key、内部 URL 或原始上游敏感信息。
- 双角色权限与跨用户隔离测试通过。
- 付费烟测默认关闭；需要时由管理员显式启用、限制为最少代表调用并记录成本。
- 发布包只包含静态前端、Python 运行时源码、受控配置示例和许可证；不含本地状态与密钥。
- 生产目录、生产端口、生产进程和 launchd 未被读取敏感数据、修改或重启。

## 14. 明确不做

- 不重写为 T8/xyflow 或另一个 Node 服务端。
- 不以大量微服务代替完成功能。
- 不一次实现所有节点、ComfyUI 和在线 Skill 市场。
- 不让普通用户保存个人 Key、添加任意服务或执行远程代码。
- 不通过 Cloudflare Workers 承载长时间模型任务或大文件整体处理。
- 不承诺单机配置即可支撑全球规模；只保证业务契约支持无状态、多实例和多地区部署。
- 不在用户批准本规格与后续实施计划前开始产品功能实现。

## 15. 后续流程

3. 使用 `writing-plans` 编写逐文件、逐测试、带验证与回滚点的实施计划。

5. 每个切片单独演示、复核和决定是否进入下一切片。
