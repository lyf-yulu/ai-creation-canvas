# 无限画布核心交互设计

日期：2026-08-10  
状态：已完成分段口头确认，等待书面设计审阅

## 目标

让当前产品页中的无限画布具备稳定、可保存、可恢复的基础交互，为后续框选、连线、ComfyUI 画布和 Skill 节点提供可靠底座。

本切片完成后，用户可以：

- 在画布空白处按住左键拖动以平移视角；
- 使用滚轮以鼠标位置为中心缩放；
- 使用可见的缩放控制调整比例或复位视角；
- 用左键拖动现有画布节点；
- 刷新、重新登录或换设备后恢复服务端保存的视角与节点位置。

## 范围边界

### 本切片包含

- 空白区域左键拖动平移；
- 滚轮缩放，范围为 5%–500%；
- 左下角缩放比例、滑杆和复位按钮；
- 提示词节点、生成节点和结果节点的拖动；
- 视口与节点位置的服务端持久化；
- 已删除、无权访问或不存在项目的安全返回；
- 桌面和窄屏布局兼容。

### 本切片不包含

- 小地图；
- Ctrl/Cmd 拖动框选；
- 多选、复制、粘贴和批量删除；
- 节点端口与连线；
- 对齐线、网格吸附和自动布局；
- 新模型、新生成工作流、ComfyUI 或 Skill 节点。

这些能力在核心导航稳定后分别作为独立切片实现。

## 交互约定

- 空白区域左键拖动：平移画布。
- 滚轮：以鼠标所在位置为中心缩放。
- 节点左键拖动：移动节点，不触发画布平移。
- Ctrl/Cmd 加拖动：本切片不执行框选，但保留事件边界供后续接入。
- 缩放滑杆：在 5%–500% 范围内连续调整。
- 复位按钮：恢复 `x=0`、`y=0`、`k=1`。
- 小地图入口在本切片隐藏，避免展示尚未完成的功能。

## 架构与组件边界

### `InfiniteCanvas`

只负责视口坐标变换和画布级输入：

- 计算平移后的 `x/y`；
- 计算以指针为中心的缩放结果；
- 限制缩放范围；
- 阻止画布滚轮带动外层页面；
- 通过 `onViewportChange` 输出新的视口，不直接访问项目存储或网络。

### 产品画布页

负责把通用交互连接到当前项目：

- 从项目文档读取初始 `viewport`；
- 把视口变化写回当前项目状态；
- 渲染缩放控制；
- 将节点拖动交给独立节点交互层；
- 项目不存在或无权访问时返回项目列表。

### 节点交互层

节点拖动逻辑不写进生成节点、结果节点等业务组件。统一交互层负责：

- 记录拖动开始时的指针和节点世界坐标；
- 使用当前缩放比例把屏幕位移换算成世界坐标位移；
- 拖动期间只更新内存状态；
- 指针释放时保留最终位置，由现有项目同步机制合并保存；
- 阻止节点指针事件继续触发画布平移。

业务节点仍只负责展示内容和业务动作。

### 项目同步层

沿用现有服务端项目文档和版本控制，不创建第二套画布存储：

- `viewport` 与 `nodes[].position` 都属于项目文档；
- 高频变化先进入内存中的项目状态；
- 停止操作约 400 毫秒后保存最新文档；
- 保存期间出现新变化时，不排队发送旧快照，只保留最新状态；
- 版本冲突继续使用现有冲突副本策略，禁止静默覆盖另一设备的数据。

## 数据流

### 打开项目

1. 项目同步层从服务端读取用户有权访问的项目文档。
2. 产品画布页从项目文档读取 `viewport` 和节点位置。
3. `InfiniteCanvas` 按该视口渲染世界坐标系。
4. 如果项目不存在、已删除或无权访问，页面跳转到 `/canvas`，不展示可继续操作的死页。

### 平移或缩放

1. `InfiniteCanvas` 接收指针或滚轮事件。
2. 组件计算新的 `ViewportTransform`。
3. 产品画布页立即更新当前项目的内存状态。
4. 项目同步层在静默窗口后保存最新项目文档。

### 拖动节点

1. 节点交互层截获节点上的左键按下。
2. 屏幕位移除以当前缩放比例，得到世界坐标位移。
3. 节点位置即时更新，画布视口保持不变。
4. 指针释放后，项目同步层保存最终节点位置。

## 异常与冲突处理

- 网络保存失败：保留用户当前画面，不回滚到旧位置；显示非阻塞提示，下一次项目变化再次尝试保存。
- 服务端版本冲突：不覆盖远端新版本，沿用冲突副本策略保存本地工作。
- 项目被删除或用户失去权限：后续读取返回未找到，客户端回到项目列表。
- 指针取消或窗口失焦：结束当前拖动并清理临时交互状态，避免鼠标释放后仍持续移动。
- 非有限坐标：在进入项目状态前拒绝 `NaN` 和无穷值，避免破坏项目文档。
- 旧项目缺少合法视口：使用 `{ x: 0, y: 0, k: 1 }`，不影响节点数据。

## 性能约束

- 指针移动期间每个动画帧最多提交一次界面更新。
- 网络保存继续由项目同步层防抖，不为每次 `pointermove` 发请求。
- 本切片不引入新的画布框架或大型依赖。
- 节点数量仍受现有服务端项目文档上限约束。

## 安全与隔离

- 所有持久化继续经过同源 `/api/v1/projects`。
- 服务端按当前登录用户校验项目归属。
- 客户端项目 ID 不能扩大访问权限；无权项目按不存在处理。
- 不向浏览器新增 API Key、服务地址或动态脚本配置。

## 验收标准

### 自动化测试

- 空白区域左键拖动后，视口 `x/y` 按位移变化。
- 滚轮缩放保持鼠标下的世界坐标不漂移，并限制在 5%–500%。
- 缩放滑杆和复位按钮同步更新画布。
- 节点在 50%、100% 和 200% 缩放下按正确世界距离移动。
- 拖动节点不会触发画布平移。
- 指针取消会结束拖动。
- 高频交互只保存最终状态。
- 刷新后恢复服务端保存的视口与节点位置。
- 网络失败不会损坏当前内存状态。
- 版本冲突不会覆盖远端项目。
- 普通用户不能读取或修改其他用户的视口与节点位置。
- 无效或已删除项目自动返回项目列表。

### 真实页面验收

桌面和窄屏各执行一次：

1. 创建画布并添加至少两个节点。
2. 平移画布并调整为非 100% 缩放。
3. 在不同缩放比例下拖动节点。
4. 刷新页面并重新进入项目。
5. 确认视角、缩放比例和节点位置恢复。
6. 确认右侧生成面板、底部任务栏与缩放控制互不遮挡。
7. 确认控制台没有未处理错误，保存请求没有形成高频风暴。

1. 框选、多选与键盘操作；

4. 对齐、吸附和自动布局；
5. ComfyUI 画布与内置 Skill 节点接入。
