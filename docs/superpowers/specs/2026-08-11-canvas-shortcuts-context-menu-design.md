# 画布快捷操作与右键创建设计

状态：用户已授权自主迭代并完成后统一验收。

## 目标

在不破坏文本编辑、用户隔离和现有命名端口图结构的前提下，为无限画布补齐常用桌面操作：复制、剪切、粘贴、全选、删除、节点重命名，以及在空白处右键按当前位置创建节点。

## 交互合同

- `Ctrl/Cmd+C` 复制当前选中节点；`Ctrl/Cmd+X` 复制后删除；`Ctrl/Cmd+V` 粘贴；`Ctrl/Cmd+A` 选择全部节点。
- `Delete/Backspace` 保持删除节点或连接；`F2` 重命名单个选中节点。
- 输入框、文本域、下拉框和 `contenteditable` 内不拦截上述文本编辑快捷键。
- 节点右键菜单提供复制、剪切、重命名和删除。若右键节点已经属于多选集合，保留整个多选集合；否则切换为单选。
- 空白处右键菜单提供提示词、参考图片、参考视频、参考音频、图片生成、视频生成六类节点，并在右键对应的画布世界坐标创建。只读模式保留浏览器原生菜单且不允许创建。
- 右键菜单可用键盘进入、方向键移动、Enter/Space 执行、Escape 关闭并恢复焦点；菜单必须限制在可视区域内。

## 剪贴板与数据安全

- 剪贴板仅存在于当前页面内存，不写系统剪贴板、不持久化。
- 剪贴板绑定当前浏览器存储作用域版本；退出、切换用户或作用域变化立即清空，因此资产 ID 不会跨用户复用。
- 快照深拷贝节点，只保留被复制节点之间的连接。粘贴为所有节点与连接生成新 ID，并以 32px 递增偏移保留相对布局。
- 模型节点粘贴后清除 `jobId`、`jobStatus`、`idempotencyKey`、请求编号和运行状态，恢复为未运行，防止重复付费或错误恢复旧任务。
- 目标画布已有提示词时，包含提示词的粘贴整体拒绝；不做部分粘贴。节点或连接超过服务端上限时同样整体拒绝。

## 组件边界

- `features/graph/canvas-clipboard.ts`：纯函数生成快照、校验作用域并构造粘贴结果。
- 页面负责快捷键路由、选择状态、用户提示和调用项目更新。
- `CanvasNodeContextMenu` 扩展节点操作；新增 `CanvasCreateContextMenu` 负责空白创建选择。
- 新增轻量重命名对话框，只编辑节点 `title`，裁剪空白并限制长度。

## 验证

- 纯函数测试覆盖 ID/连接重映射、相对位置、任务字段清理、提示词唯一性、容量边界与作用域失效。
- 页面测试覆盖 Mac/Windows 修饰键、文本编辑不拦截、多选复制剪切、重复粘贴、F2/右键重命名、只读保护。
- 真实 Chromium 测试覆盖缩放和平移后在空白右键创建节点、菜单可视区域和刷新恢复。

## 本轮不包含

- 不与操作系统剪贴板交换 JSON。
- 不实现撤销/重做；后续可在稳定命令模型基础上单独增加。
- 不复制外部插件无法声明的私有运行时状态；插件的可序列化节点字段仍会保留。
