AI 创作画布 · 管理员操作指南

本指南写给负责日常管理的非技术同事。所有操作都在浏览器网页里完成，
不需要登录服务器、不需要运行任何命令。


一、登录

1. 用公司内网电脑打开浏览器，访问：

   http://172.16.0.90:8992/login

   （如果公司技术人员给了别的地址，以技术人员给的为准）

2. 输入管理员账号和密码登录。账号一般是 canvas-admin，
   密码由技术人员在第一次交付时提供。

3. 如果登录后提示"修改密码"，按提示设置一个新密码（至少 12 位），
   以后就用新密码登录。这个新密码只有你自己知道，忘了找技术人员重置。


二、导入方舟生成 Key（第一次使用必须做）

这个 Key 是图片和视频生成功能的"钥匙"，由公司向火山方舟购买后提供。

1. 登录后，进入「模型与调用线路」页面。

2. 找到「导入方舟生成 Key」区域，点里面的「下载示例 JSON」按钮，
   浏览器会下载一个文件：ark-key.example.json

3. 用记事本（Windows）或文本编辑（Mac）打开这个文件，内容类似：

   {"version": 1, "api_key": "replace-with-ark-api-key"}

   把 replace-with-ark-api-key 这串文字替换成公司提供的真实 Key，
   引号不要动，然后保存（保存时编码选 UTF-8，Windows 记事本默认就是）。

4. 回到网页，「选择 Key JSON」选择你刚保存的文件。

5. 勾选「确认替换现有方舟 Key」，再点「导入并替换方舟 Key」。

6. 看到绿色提示「方舟 Key 已导入，新任务立即生效」就成功了。

说明：
   网页上永远不会显示 Key 的内容，这是安全设计，不是出错。
   以后要换 Key，重复第 2 到 6 步即可，不需要重启任何东西。


三、把模型派发给用户

模型配好后，还要"派发"给用户，用户才能在画布里使用。

1. 进入「模型与调用线路」页面，找到「用户模型派发」区域。

2. 在账号列表里选择要授权的用户（比如 canvas-user）。

3. 勾选要开放给这个用户的模型：
   Seedream 5.0 Pro（图片生成）
   Seedance 2.0（视频生成）
   Seedance 2.5（视频生成）

4. 点「保存派发」，看到「派发已保存」就完成了。

5. 让用户退出重新登录，画布里就会出现这些模型。


四、配置人像资产库（需要人像生成功能时才做）

人像生成是指：上传一张真人照片，用这张照片生成视频。
这项功能需要额外的资产库配置（火山方舟 OpenAPI 与 TOS 存储的凭据）。

1. 登录后进入「人像资产库」页面。

2. 找到「导入资产库 JSON」区域，点「下载示例 JSON」，
   下载 asset-library.example.json

3. 用记事本打开，里面有几个占位值，全部替换成公司提供的真实值：

   ark_access_key   方舟 OpenAPI 的 AK
   ark_secret_key   方舟 OpenAPI 的 SK
   tos_access_key   TOS 存储的 AK
   tos_secret_key   TOS 存储的 SK
   tos_bucket       TOS 存储桶名称
   tos_region       存储区域（一般填 cn-beijing）
   project_name     项目名（可保持默认 Seedance2.0）

4. 保存后，回到网页选择这个文件，勾选「确认覆盖服务端配置」，
   点「导入」。页面只显示配置状态（是否已配置），不会显示密钥。


五、导入凭据池（可选，一般用不到）

凭据池用于管理多家供应商的多把 Key（如 Banana、GPT-Image2 等）。
如果公司只用方舟的 Seedream 和 Seedance，跳过本节。

1. 进入「模型与调用线路」页面，找到「导入凭据池 JSON」区域。

2. 点「下载示例 JSON」得到 credential-pools.example.json，
   把 replace-with-provider-key 替换成真实 Key 后保存。

3. 回到网页选择文件，勾选「确认替换现有凭据池」，点「导入并替换凭据池」。

注意：凭据池只支持系统内置的四种组合，字段名不能改：
   Seedream   对应 provider 填 ark          group 填 official   family 填 seedream
   Seedance   对应 provider 填 ark          group 填 official   family 填 seedance
   Banana     对应 provider 填 chiyun-banana       group 填 banana   family 填 nano-banana
   GPT-Image2 对应 provider 填 chiyun-gpt-image2   group 填 gpt-image  family 填 gpt-image2


六、人像资产库日常使用

1. 普通用户在人像资产库里上传虚拟人照片后，需要管理员确认。

2. 管理员进入「人像资产库」页面，查看待确认的资产，
   确认资产激活成功后，用户才能用这张照片生成视频。


七、常见问题

1. 导入提示"文件格式不正确"
   检查是不是用下载的示例改的；字段名有没有被误改；
   引号、逗号有没有多删多增；保存时是否选了 UTF-8 编码。

2. 导入方舟 Key 后，用户生成图片报错
   先确认 Key 是否正确（重新导入一次试试）；
   再确认这个用户是否已经被派发了对应模型（见第三节）。

3. 忘记管理员密码
   联系技术人员在服务器上重置，重置后第一次登录需要再改一次密码。

4. 网页打不开
   确认电脑连的是公司内网；确认地址里的端口 8992 没写错；
   都不行就联系技术人员。

5. 换 Key 后要重启吗
   不需要。导入成功后新任务立即用新 Key，已经提交的任务不受影响。


八、安全注意事项

1. Key 文件只保存在自己的电脑上，不要截图、不要发到聊天群、
   不要提交到任何代码仓库。

2. 管理员账号只给需要的人用，普通用户请使用他们自己的账号。

3. 所有导入都只在管理员页面完成；普通用户看不到这些入口，
   看到管理入口打不开是正常的。
